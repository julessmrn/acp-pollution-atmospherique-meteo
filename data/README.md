# Données

Le jeu de données `ATMO-RDSM2.rda` a été fourni dans le cadre du cours et n'est pas redistribué dans ce dépôt.

Pour relancer l'analyse, placer le fichier ici : `data/ATMO-RDSM2.rda`. Il contient un objet `atmo` avec des mesures horaires :

- **Polluants :** NO, NO₂, O₃, PM10.
- **Météo :** température, humidité, pression, variation de pression sur 3 h, point de rosée, vent moyen, pluie sur 6 h et 24 h.
- **Temps :** date de début de mesure, heure, mois, jour.
